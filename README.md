# HtmlValidate.Net

A start with HtmlValidate-like implementation of HTML validation for dotNet.

## Existing packages

I started this project before looking around for better alternatives to HtmlAgilityPack.  
I found that there are other existing packages, like AngleSharp, that are doing the same thing as I am trying to achieve.
